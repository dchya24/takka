## Yang diimplementasikan

Semua di `acp.rs`:

1. Saat `serve_over` mencapai EOF, sebelum `Ok(())`:
   - Set `cancel_requested` + forward `Request::Cancel` untuk SEMUA sesi yang
     laku; deny semua pending permission waiters (jalur T-05) supaya turn loop
     tidak dead-lock.
   - Buang registry (drain) supaya sender drop → engine idle keluar sendiri
     (`recv → Ok(None) → break`).
   - Join semua turn thread dan engine thread BOUNDED: port `join_bounded` +
     `SHUTDOWN_JOIN_TIMEOUT` (konstanta di acp.rs; nilai sekitar 15–30 s, jejas
     daemon). Straggler di-detach dengan warna tracing; proses tetap keluar.
   - `serve_over` kembali `Ok(())`; `main` exit code 0 (pastikan jalan ini tidak
     berubah perilaku main).
2. Word pada engine join: engine thread hanya berhenti setelah run aktif
   selesai — cancel flag + `Request::Cancel` memastikan itu cepat; bounded join
   menangkap yang ngambang.
3. `primera` integration: `serve()` harus menghargai pin test (karena test
   subprocess tidak boleh membacakan config ambient): jika env
   `TAKKA_TEST_ACP_CONFIG` diset, gunakan sebagai `AcpConfig.config_path`
   (HANYA jalur test; dokumentasikan komentar jelas "test-only, never set in
   production"). Jika sudah ada dari lane sebelumnya, pertahankan.
4. Tambeng helper kecil: `--acp-max-sessions N` di `main.rs` (hand-parse ala
   flag daemon yang sudah ada) build `AcpConfig { max_sessions: N, .. }`.

## Test wajib (hermetik, semua bounded ≤10s, pola `VecSink`/`ChanReader`)

1. `eof_joins_engines_and_returns_clean`: buka ≥2 sesi, satu dengan turn
   aktif (fake/SSE, ala lane T-05) + satu idle; drop reader (EOF) →
   `serve_over` kembali `Ok(())` dalam batas; sebagai tanda engine habis:
   periksa join membener (mis. hook `#[cfg(test)]` yang menghitung jumlah
   thread "acp-engine-*" yang telah diselesaikan — boleh pakai
   `Arc<AtomicUsize>` probe yang di-increment setelah join; jangan /proc).
2. `eof_during_pending_permission_unblocks`: satu sesi dengan turn
   menjungkal permission gate (dari lane T-05); EOF → waiter di-deny, turn
   selesai, join bounded, serve_over return `Ok(())`.
3. `remote subprocess exit code 0` (opsional tapi dinilai):
   spawn `env!("CARGO_BIN_EXE_takka-runtime")` dengan `--acp`,
   stdin pipa, env `TAKKA_TEST_ACP_CONFIG` → config hermetik;
   kirim `initialize` + satu `session/new`; tutup stdin; assert exit code 0
   dalam batas. Pastikan tidak menyentuh provider nyata. Kalau ini konflik
   dengan aturan test suite lintas-OS di CI, tulis di laporan dan tinggalkan
   versi in-process saja.
4. `serve_over_malformed_line_stays_alive` (kembalikan/kekalkan kontrak T-00
   jika belum diuji di bentuk baru): baris non-JSON → satu frame parse error,
   koneksi tetap hidup.
