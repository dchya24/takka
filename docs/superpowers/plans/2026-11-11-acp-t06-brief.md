## Yang diimplementasikan

Modul pure mapping — tanpa I/O, tanpa engine, tanpa state koneksi:

```rust
//! Permission bridge takka ⇄ ACP v1 (story T-06, unit-level).
//! (#) Dinonwire sampai T-05 mengintegrasikan turn loop; modul diregister dari
//! takka-runtime/src/main.rs / acp.rs oleh integrator.
#![allow(dead_code)]

use agent_client_protocol_schema::v1 as acp;

/// D8: satu pasangan default `allow_once`/`reject_once`;
/// `*_always` hanya muncul bila tool ada di jalur auto-approve (T-05 dialan).
pub(crate) fn permission_options() -> Vec<acp::PermissionOption>

/// ConfirmationRequest.action → ToolKind yang dirender editor:
/// run/run_command/run_script → Execute; write/edit/apply_patch → Edit;
/// delete → Delete; read → Read; move → Move; lain → Other.
pub(crate) fn permission_tool_kind(action: &str) -> acp::ToolKind

/// Bangun permintaan permission: ToolCallUpdate (id = id request outbound
/// unik, title = description, kind = mapping), options D8.
pub(crate) fn permission_request(
    session_id: &str,
    outbound_id: &str,
    action: &str,
    description: &str,
) -> acp::RequestPermissionRequest

/// Outcome klien → approved?
/// Cancelled → false; Selected("allow_once"/"allow_always") → true;
/// Selected lainnya (reject_*) → false.
pub(crate) fn outcome_approves(outcome: &acp::RequestPermissionOutcome) -> bool

/// Outcome → Request::ConfirmResponse yang kembali ke engine (approved bool).
pub(crate) fn confirm_response(request_id: Option<String>, approved: bool)
    -> takka_core::runtime::protocol::Request
```

## Test wajib (hermetik, tanpa provider; `mod tests` dalam file yang sama)

1. Wire shape: `permission_request("sess-1", "perm-1", "run", "delete the build dir")`
   diserialisasi → `{"sessionId":"sess-1","toolCall":{"toolCallId":"perm-1",
   "title":"delete the build dir","kind":"execute"},"options":[{"optionId":"allow_once",
   "name":"Allow","kind":"allow_once"},{"optionId":"reject_once","name":"Reject",
   "kind":"reject_once"}]}` — sesuaikan asersi dengan bentuk buat crate (baca
   serialisasi aktual, lalu pin bentuknya dengan pernyataan eksplisit per field
   penting; jangan string-compare penuh jika crate menambah field _meta).
2. `outcome_approves`: allow_once → true; allow_always → true; reject_once →
   false; reject_always → false; Cancelled → false.
3. `permission_tool_kind` semua mapping di atas + default → Other.
4. `confirm_response(false)` → Request::ConfirmResponse dengan approved=false
   (assert via match/serde).
